# Quick GitHub Pages deployment

1. Download and extract `notewing-free-github-pages.zip`.
2. Create a new public GitHub repository named `notewing-free`.
3. Upload the files inside the extracted `notewing-free` folder to the repository root.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch**, branch **main**, folder **/(root)**, then click **Save**.
6. Open the published Pages URL shown on that screen.

For microphone access, use the published HTTPS site or run locally with:
`python3 -m http.server 8000`
